Installing takes a minute

The app isn't on the Play Store yet, so Android will ask for one-time permission to install it.

1

Download the APK

Tap the download button above. It saves to your phone's Downloads folder.

2

Allow this install

Open the file. Android will ask to allow installs from this source. Tap Settings, then allow it. This is a one-time step.

3

Open OmniView

Grant file access when asked, and you're straight into your files. No account, no sign-up.

Using it on iPhone

The iPhone version is a web app, not an App Store app. It opens straight from Safari and works offline once it has loaded.

1

Open the web app in Safari

Go to this page in Safari. It must be Safari, other browsers on iPhone can't add apps to the home screen.

2

Add it to your home screen

Tap the Share button, scroll down, and choose Add to Home Screen. OmniView now has its own icon and opens full screen.

3

Pick a file to open

Tap Choose a file and select a PDF, Word, Excel, PowerPoint, photo, video or code file from the Files app. Nothing is uploaded.

One difference from Android: iPhone does not let any web app browse the whole phone, so you choose each file yourself instead of scrolling through all of them.
